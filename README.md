# Trading Signal App

A paper-trading and market-analysis web app designed to test rule-based trading strategies before risking real money.

## Version 1 goals

- $10,000 simulated account
- Stock scanner
- BUY / SELL / WAIT signals
- Entry, stop-loss, and profit-target calculations
- Position sizing with a default 1% maximum account risk per trade
- Trade history and performance metrics
- Market data integration (Alpaca planned)
- Paper trading only — no live order execution

## Important

Trading involves risk. Signals are probabilistic and do not guarantee profits. Version 1 is intentionally designed for simulation and strategy testing.
